Get the instrument.

Metabasis is built as an Android debug APK for testing and inspection. Releases are unsigned while the project is in v1.

Download from GitHub

Use the latest tagged release for a straightforward APK download. For the newest in-progress build, open a successful Android debug workflow and download the metabasis-debug-apk artifact.

Open GitHub releases

Install

Download app-debug.apk on an Android 8.0+ device. Android may warn that the APK is unsigned or from an unknown source. This is expected for the v1 debug workflow.

What the current build includes

Base, Traces, and Tune; local hardware step counting with an approximate fallback when needed; evolving five-stage themes; haptic ticks; a calendar heatmap; and local JSON import/export.

Validate on your phone

Real-device checks should cover sensor behavior, background battery restrictions, small-screen layout, accessibility contrast, and the light/dark chassis choices.
